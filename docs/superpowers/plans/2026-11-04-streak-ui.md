# Streak UI, Play again and table looks (daily habit PR 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app shows the shared "Us" streaks PR 3 built on the server: the Home badge, the Us screen (pairs, today's paws, week strip, condo, toys, naps, pause, pin, leave and the ghosted cat), the stamp at the table, gifts and celebrations, Play again, the table menu's look tray applied to the SpriteKit table, and the sign-in cloud at streak 3. It also turns `STREAKS` on in production.

**Architecture:** Wire types, the streak store, badge mapping, table-pair choice, celebration diffs and look-tray rules are pure PounceKit code with Swift Testing tests. `StreakStore` (main actor, observable) talks to a `StreakService` protocol: `APIClient` in real runs, `DemoStreakService` (from `DemoFixtures.streaks()`) under the Debug flag `-demo-streaks`. The socket path gains `{t:"streak"}`, `{t:"rematch"}`, the `look` event and the snapshot's `look`/`rematch`; `RoomStore` folds them in and `RoomSession` forwards streak views to the app's `StreakStore`. SwiftUI draws everything; the table scene swaps its rug and card back. New art goes into `Art/manifest.json` as placeholders (`_ph`) under the §9.6 names so PR 8 swaps real art in by file name. The server gains one small route pair for the ghosted cat (PR 3 left it for later).

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI, SpriteKit, Swift Testing, XCUITest; TypeScript Workers + vitest + Miniflare; ImageMagick for placeholders.

**Spec:** `docs/superpowers/specs/2026-11-04-daily-habit-design.md` (§5, §6–§9, §10.1–§10.5, §14 "Leaving a streak", §15 row 4, §16). Server contract: `docs/superpowers/plans/2026-11-04-server-streaks.md` and PR #24.

## Global Constraints

- iOS 26.0, Swift 6 strict concurrency, Apple frameworks only, XcodeGen `project.yml` (new files are picked up by folder).
- No emoji anywhere. On screen only names, table names and numerals; everything else is art or icons. No guilt copy, no countdown timers, nothing shows who missed a day (settled days show only kept, nap, held, paused or a plain grey dot; `missed` draws like `none`).
- Loud Toy palette (violet, magenta, teal, orange, sky, lime, ink); never beige or muted.
- Everything streak-shaped degrades cleanly: a 404 from `GET /v1/me/streaks` means streaks are off (no badge, no Us screen, no cloud); a snapshot without `look` means no look tray and no Play again.
- Sign-in cloud: never on a kitten's device (`AccountModel.offersSignIn`), never once signed in.
- Gifts open on Home or the Us screen, never mid-table.
- Art names: `condo-1`…`condo-10`, the 24 `toy-*` ids, the 7 `back-*` and 5 `rug-*` ids from `apps/play-api/src/streaks/catalog.ts`, `gift-box`, `gift-box-open`, `paw-badge-grey|one|both|nap|bandage|suitcase`, `pounce-bell`, `cats-asleep-condo`, plus `icon-pause`, `icon-pin`, `icon-trash`, `icon-rug`, `icon-cloud-plus`, `icon-best`, `icon-days`, `icon-weeks`, `icon-replay`. All `_ph` placeholders.
- Debug-only stubs and demos (`#if DEBUG`).
- Never touch :4343, the physical iPhone, other sessions' simulators or the shared :8787 server. Own simulators and a private dev server port.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Decisions where the spec is silent

1. The Us screen shows the phone owner's pairs (`?person=<owner>`); a household person's views arrive only by socket and only drive the table badge.
2. The table badge picks, among this phone's seated people's pairs, the first (top) pair whose `myMove ∪ theirMove` holds this table, or that was reported on this table's socket, or whose partner's name and cat match another human seat.
3. Badge nap blanket: yesterday's dot is `nap` and today isn't kept. Bandage: `winback` non-null. Suitcase: `pausedUntil` non-null. Fresh start: count 0 with best > 0 (cats asleep, sparkle).
4. The cloud shows while not signed in, sign-in is offered, and any of the owner's pairs has `count >= 3` or `best >= 3`; tapping it runs Sign in with Apple for the owner.
5. Play again shows only when the room's snapshot has `look` (the server has the feature). The phone that asked jumps to the new table on `{t:"rematch"}`; others' pill turns into a bouncing jump to the same code.
6. The Us screen's Pounce bell and settings gear wait for PR 5 (they need its sheet and settings panel). The Play pill (no shared table in play) creates a new game until Pounce exists.
7. Ghosted cat: the server lists `left: [{pair, partner:{name,cat}}]` in `GET /v1/me/streaks` and takes `DELETE /v1/me/left/{pair}`, which clears the tombstone and makes a fresh pair at 0 at once.
8. Condo stage drop and milestone celebrations key on the last stage/count this phone saw per pair, kept in `streak-seen.json`.
9. A `look` event changes `room.look` and folds in like presence (no table intent); the rug cross-fades at once and the card back applies to cards drawn from then on.

## Review Focus

1. **Streaks off (prod before deploy, old servers):** a 404 must hide the badge, Us screen and look tray with no error state or retry loop. Test: `StreakStoreTests.testNotFoundTurnsStreaksOff`, `testOfflineKeepsLastList`.
2. **A `look` or `streak` message from a server the app half-understands:** unknown week states and missing optional fields decode. Test: `StreakWireTests.testUnknownWeekStateIsNone`, `testMissingOptionalsDecode`.
3. **Several pairs at a family table:** the table badge shows the top one, never a pair not at this table. Test: `TableStreakTests.testPicksTopPairAtThisTable`, `testIgnoresPairsElsewhere`.
4. **Double taps on Play again / gift / pause:** one request; Play again sends `rematch` once until answered. Test: `PlayAgainTests.testSendsOnce`, `StreakStoreTests.testOpenGiftOnce`.
5. **A look the setter doesn't own:** the tray only offers defaults plus own unlocks; `not_unlocked`/`too_soon` shake the tile and leave the look as it was. Test: `LookTrayTests.testOffersDefaultsAndOwnUnlocks`, UI `LookTrayTests.testTraySetsRug`.
